# Security Policy

## Reporting a vulnerability

Please report privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** (private vulnerability reporting / security advisories). Do not open a public issue for a vulnerability.

Include the affected version, steps to reproduce and the impact. Never include real tokens, API keys or credentials in a report; redact them. If you find that a secret has been exposed, revoke it first.

You can expect an acknowledgement and a fix or mitigation plan as soon as the maintainer is able. Only the latest release is supported.
