# Integration icons

Unmodified vendor-published PNG app icons, downloaded 2026-11-09:

- Linear: https://linear.app/static/apple-touch-icon.png?v=2
- Notion: https://www.notion.com/front-static/logo-ios.png
- Google Calendar: https://ssl.gstatic.com/calendar/images/dynamiclogo_2020q4/calendar_31_2x.png

These marks identify the connected services; their trademarks belong to their respective owners. They are embedded at compile time, so displaying them makes no network requests. The calendar row shows Google Calendar and Notion side by side because both read the same macOS calendar account; it does not imply a direct Notion API integration.
